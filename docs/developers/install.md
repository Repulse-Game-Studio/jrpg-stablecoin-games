# Install

1. Unzip the release into your project so you get:
   ```
   game/scfg/                      (screens, API, browser checkout page)
   game/python-packages/scfg_core/ (the engine; plain Python)
   ```
2. Add your configuration in any `.rpy` file: see [Configure](configure/README.md).
3. Start with `testnet=True` and do a full [test purchase](testing.md) before going live.
